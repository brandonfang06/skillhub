## Upstream Release Scope

`v0.2.11` must be tracked from the final tag diff, not release text or a
single commit title. The release contains these final-scope changes:

- `fix(publish)`: accept case-insensitive `SKILL.md` uploads.
- `feat(skill)`: add namespace search. Namespace bundle download was introduced
  during the release branch and then removed from the final backend/API surface.
- `feat(bootstrap)`: sync built-in skills from a cloud manifest.
- `feat(web)`: preview relative markdown package links.
- `chore(logging)`: include idempotency cleanup threshold in logs.

## Impact Triage

| Area | Upstream files | Python follow-up decision |
| --- | --- | --- |
| Case-insensitive `SKILL.md` package validation | `MultipartPackageExtractor`, `ZipPackageExtractor`, `SkillPackagePolicy`, publish tests | Port to Python now. This is upload compatibility and should be verified against Python package extraction. |
| Namespace search | Web search query parsing, search page, namespace search E2E | Backend namespace search is already present in Python. Port the missing frontend namespace query UX and regression tests. Do not port namespace bundle download unless a later upstream tag reintroduces it. |
| Built-in skills cloud manifest bootstrap | Java bootstrap classes, V43 migration, `builtin-skills/manifest.json`, docs, password reset boundary tests | Plan as a dedicated milestone. It adds a system account, protects that account from password reset/admin flows, and introduces remote package bootstrap behavior, so schema and bootstrap semantics must be ported deliberately. |
| Relative markdown package links preview | Web markdown renderer, skill detail tests, package-relative-link utility | Accept/port frontend if not already present. Backend impact depends on file content/download route parity. |
| Idempotency cleanup logging | Java task logging | Low-risk. Port only if Python has equivalent cleanup task logging. |
