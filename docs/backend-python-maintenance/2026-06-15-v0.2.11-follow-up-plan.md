## Upstream Release Scope

`v0.2.11` contains these high-level changes:

- `fix(publish)`: accept case-insensitive `SKILL.md` uploads.
- `feat(skill)`: add namespace search and bundle download.
- `feat(bootstrap)`: sync built-in skills from a cloud manifest.
- `feat(web)`: preview relative markdown package links.
- `chore(logging)`: include idempotency cleanup threshold in logs.

## Impact Triage

| Area | Upstream files | Python follow-up decision |
| --- | --- | --- |
| Case-insensitive `SKILL.md` package validation | `MultipartPackageExtractor`, `ZipPackageExtractor`, `SkillPackagePolicy`, publish tests | Port to Python now. This is upload compatibility and should be verified against Python package extraction. |
| Namespace search and bundle download | Java domain/service changes, web search/namespace pages, OpenAPI schema | Audit before port. Determine whether Python already has equivalent namespace search/download routes and whether frontend expects new API fields. |
| Built-in skills cloud manifest bootstrap | Java bootstrap classes, V43 migration, `builtin-skills/manifest.json`, docs | Plan as a dedicated milestone. It adds a system account and remote package bootstrap behavior, so schema and bootstrap semantics must be ported deliberately. |
| Relative markdown package links preview | Web markdown renderer, skill detail tests, package-relative-link utility | Accept/port frontend if not already present. Backend impact depends on file content/download route parity. |
| Idempotency cleanup logging | Java task logging | Low-risk. Port only if Python has equivalent cleanup task logging. |
