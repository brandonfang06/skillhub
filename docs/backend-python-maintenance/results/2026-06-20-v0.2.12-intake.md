# v0.2.12 Intake Result

Date: 2026-06-20

## Summary

Upstream `iflytek/skillhub` `v0.2.12` is a necessary follow-up for this
Python-only fork. The release contains user-visible CLI install/search changes,
security hardening, promotion review behavior changes, notification fixes, and
release-path hardening. Because the upstream backend implementation is Java and
this branch is Python-only, the correct follow-up is behavior porting and
contract adaptation, not file-for-file merging.

## Milestone 2 Result

Status: completed.

Python CLI API changes:

- `/api/cli/v1/skills/search` now validates a provided bearer token before
  searching and returns 401 for invalid bearer tokens instead of falling back
  to anonymous search.
- CLI search now passes `installable_only=True` into the repository.
- Repository search applies installable filtering before count and pagination:
  latest version must be `PUBLISHED`, `download_ready = TRUE`, and not yanked.
- `/api/cli/v1/skills/{namespace}/{slug}/resolve` now validates bearer tokens
  and uses installable-only version resolution for database-backed calls.
- CLI latest/version download routes now validate bearer tokens and use
  installable-only download access for database-backed calls.
- Web/portal download routes keep their existing manager preview behavior; the
  stricter installable rule is isolated to CLI install/download paths.
- Bearer scheme parsing is case-insensitive, and malformed bearer headers fail
  closed before session fallback.

Tests added/updated:

- CLI route tests for invalid bearer fail-closed behavior on search, resolve,
  and download.
- CLI route tests proving search forwards `installable_only=True`.
- Repository test proving installable filters are applied to both count and
  page queries.
- Download helper tests proving installable access requires published,
  download-ready, non-yanked versions.
- Auth test proving malformed bearer headers cannot fall back to an existing
  session.
- Mock-auth CLI flow expectation updated for the new search reader contract.

## Milestone 3 Result

Status: completed.

TypeScript CLI changes:

- `skillhub search` now accepts `--token`; explicit `--token` wins over
  `SKILLHUB_TOKEN` and stored credentials through the existing token
  resolution order.
- Search/install bad bearer flows fail with auth errors and do not retry
  anonymously.
- Interactive install target selection treats Enter on the highlighted
  multiselect row as selecting that row.
- Downloads are read through a bounded response helper with a 100 MiB package
  limit.
- Zip extraction validates central directory metadata before writing files:
  rejects zip64, multidisk archives, more than 500 entries, single entries over
  10 MiB, total uncompressed data over 100 MiB, malformed central directory,
  and unsafe paths before partial extraction.
- Install extracts to a temporary sibling directory and only renames into the
  final skill directory after extraction and metadata writes succeed. Failed
  replacement keeps the old install directory and inventory intact.

Tests added/updated:

- Search integration tests for `--token`, auth error output, and no anonymous
  retry.
- Install integration test proving bad token stops after resolve 401 and never
  downloads anonymously.
- Interactive resolver unit test for highlighted Enter behavior.
- Archive unit tests for pre-write safety, entry count, single-file size, and
  total uncompressed size limits.
- Install-service unit tests for atomic replacement failure and bounded
  content-length rejection.

## Milestone 6 Result

Status: completed.

Release/frontend/docs changes:

- CLI README now documents `skillhub search --token`.
- Dashboard review route accepts `?type=skill|profile`.
- Dashboard review page uses the requested review type as controlled tab state
  and disables skill-review queries while the profile review tab is active.
- Profile review notifications route to `/dashboard/reviews?type=profile`
  instead of the legacy skill review detail route.
- Vite JavaScript build target follows upstream `es2020`; CSS target remains
  on the legacy browser list.

Adaptation decisions:

- Upstream `SKILLHUB_DOWNLOAD_ANON_COOKIE_SECRET` release-runtime changes were
  not ported because the Python backend does not implement the anonymous
  download cookie rate-limit feature or read that environment variable.
- Upstream Playwright CSRF helper was not ported because the current Python
  backend does not issue `XSRF-TOKEN`; copying that helper would break Python
  e2e session setup.
- Java/Spring runtime script changes remain non-goals for the Python-only
  deployment path.

Review follow-up fixed during this milestone:

- CLI force install now backs up the existing install directory before moving
  the replacement into place, restores the old directory/inventory if inventory
  writes fail, and deletes the backup only after successful replacement.

Tests added/updated:

- Review page test proves `?type=profile` disables skill review queries.
- Notification target test proves `PROFILE_REVIEW` routes to the profile review
  tab.
- Existing CLI install-service tests cover force replacement, stale inventory
  cleanup, extraction failure preservation, and package-size rejection.
