# v0.2.11 Milestone B Result: Publish Package Parity

Date: 2026-06-15

## Scope

Port upstream `v0.2.11` publish compatibility for case-insensitive `SKILL.md`
paths.

Upstream reference:

- `SkillPackagePolicy.canonicalizeSkillMdPath(...)`
- `ZipPackageExtractor.normalizeEntryPath(...)`
- `MultipartPackageExtractor.normalizePath(...)`

## Changes

- Added Python package canonicalization for paths whose final segment is
  case-insensitively equal to `SKILL.md`.
- Applied the behavior at `normalize_entry_path(...)`, so ZIP extraction,
  multipart upload extraction, validation, storage keys, and manifest generation
  share the same canonical path.
- Added `server-python/tests/__init__.py` so local `tests.support` imports do
  not resolve to a third-party `tests` package from site-packages.
- Added `server-python/tests/conftest.py` to pin AnyIO tests to `asyncio`,
  matching current project dependencies. The project does not declare `trio`.
