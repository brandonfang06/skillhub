# v0.2.11 Milestone D Result: Built-In Skills And System Account

Date: 2026-06-15

## Scope

Port upstream `v0.2.11` built-in skill bootstrap and system-account protections
to the Python runtime.

Upstream references:

- `V43__user_account_system_account.sql`
- `UserAccount.systemAccount(...)`
- `PasswordResetService.isEligibleForReset(...)`
- `AdminUserAppService.rejectSystemAccountMutation(...)`
- `BuiltinSkillManifestLoader`
- `BuiltinSkillRemotePackageDownloader`
- `BuiltinSkillInitializer`

## Changes

- Added `user_account.system_account` to the Python SQLAlchemy model.
- Added Flyway-compatible migration
  `server-python/app/db/migration/V43__user_account_system_account.sql`.
- Advanced the Python schema baseline marker from
  `skillhub_flyway_v42_baseline` to `skillhub_flyway_v43_baseline` so fresh
  Python database initialization includes the new system-account migration.
- Added an existing-database compatibility path so v42 Python databases apply
  `V43__user_account_system_account.sql` before being stamped as v43.
- Protected system accounts from admin role/status mutation.
- Prevented admin-triggered and local email password reset from issuing reset
  codes for system accounts.
- Added Python built-in skill manifest support:
  - bundled manifest at `server-python/app/builtin_skills/manifest.json`;
  - manifest parsing with item cap, required fields, duplicate filtering, and
    slug validation;
  - URL allowlist for `https://bjcdn.openstorage.cn` and subdomains;
  - bounded package download;
  - package validation through the normal Python package extractor;
  - background startup synchronization using the normal publish write pipeline.
- Added K8s env exposure for `SKILLHUB_BUILTIN_SKILLS_ENABLED` in both
  kustomize and plain backend manifests.
- Documented built-in skill bootstrap envs in
  `deploy/k8s/environment-variables.zh.md`.

## Notes

- Built-in skill synchronization is best-effort and runs in a background task
  after backend startup, matching the upstream async startup behavior.
- Operators that cannot reach `bjcdn.openstorage.cn` from the backend Pod should
  set `SKILLHUB_BUILTIN_SKILLS_ENABLED=false`.
- `SKILLHUB_BUILTIN_SKILLS_MANIFEST_PATH` can point to a mounted replacement
  manifest if an organization wants to override the bundled upstream manifest.
