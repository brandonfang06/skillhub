# v0.2.11 Milestone C Result: Frontend Release Parity

Date: 2026-06-15

## Scope

Port the frontend-facing parts of upstream `v0.2.11` that are still relevant to
the final release tag:

- Namespace-aware search input and URL state.
- Relative package markdown links in skill overview documentation.

The namespace bundle download commits were not ported because the final
`v0.2.11` tag removed that backend/API surface.

## Changes

- Added namespace-aware search parsing:
  - `@team-ai release notes` becomes `namespace=team-ai&q=release notes`.
  - Bare `@team-ai` searches the namespace with an empty keyword.
- Updated the search route and search page to preserve namespace state through
  sort, label, pagination, and starred-only interactions.
- Added relative package link resolution for skill overview markdown.
- Updated markdown rendering so link clicks can be intercepted by the skill
  detail page while external links and same-document anchors keep browser
  behavior.
- Added i18n keys for the namespace filter chip and missing package file toast.
