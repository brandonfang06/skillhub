# Upstream v0.2.17 Admin Namespace Contract

Date: 2026-08-23

## Scope

Port the upstream `v0.2.17` administrator namespace management behavior to the
Python backend and React frontend without changing the existing Namespace
Analytics page or weakening ordinary namespace membership rules.

All routes below are session-only, require `SUPER_ADMIN`, and use only the
`/api/v1` prefix. A valid bearer token is rejected with
`error.apiToken.endpoint.unsupported`; an invalid bearer token remains 401.

## Route Contract

| Method | Route | Contract |
| --- | --- | --- |
| GET | `/api/v1/admin/namespaces` | Filter by optional keyword, status, and type; page and size default to 0 and 20. |
| GET | `/api/v1/admin/namespaces/{slug}` | Inspect one namespace without requiring namespace membership. |
| GET | `/{slug}/members` | Page namespace members. |
| GET | `/{slug}/member-candidates` | Search ACTIVE non-members; size caps at 20. |
| POST | `/{slug}/members` | Add one non-OWNER member. |
| POST | `/{slug}/members/batch` | Add members with durable per-item partial success. |
| PUT | `/{slug}/members/{userId}/role` | Change a non-owner to MEMBER or ADMIN. |
| DELETE | `/{slug}/members/{userId}` | Remove a non-owner. |
| POST | `/{slug}/transfer-ownership` | Atomically transfer the sole OWNER role to an existing member. |
| POST | `/{slug}/freeze` | `ACTIVE -> FROZEN`; optional reason up to 512 characters. |
| POST | `/{slug}/unfreeze` | `FROZEN -> ACTIVE`. |
| POST | `/{slug}/archive` | `ACTIVE` or `FROZEN -> ARCHIVED`; optional reason. |
| POST | `/{slug}/restore` | `ARCHIVED -> ACTIVE`. |

List keyword matching is case-insensitive across slug, display name, and
description. Status accepts `ACTIVE`, `FROZEN`, or `ARCHIVED`; type accepts
`TEAM` or `GLOBAL`. Invalid values return 400. Pages clamp to zero, size caps
at 100, and ordering is `updated_at DESC, slug ASC`.

Top-level stats count all namespaces by lifecycle state and are not filtered.
Per-namespace member counts include all memberships and skill counts include
all skill containers. These management counts intentionally do not reuse the
eligible-catalog semantics of `/admin/namespace-analytics`.

## Response Contract

An admin namespace response contains identity/profile fields, created/updated
timestamps, `stats.memberCount`, `stats.skillCount`, and permissions:

- `currentUserRole` is the real membership role or null.
- `platformOverride` is true for this SUPER_ADMIN surface.
- `immutable` is true for GLOBAL.
- capability flags cover member management, governance, publishing, ownership
  transfer, freeze/unfreeze, archive, and restore.

GLOBAL is inspectable but immutable. TEAM capabilities are:

| Status | Members | Publish | Transfer | Freeze | Unfreeze | Archive | Restore |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| ACTIVE | yes | yes | yes | yes | no | yes | no |
| FROZEN | no | no | no | no | yes | yes | no |
| ARCHIVED | no | no | no | no | no | no | yes |

## Python Adaptation Decisions

- Use dedicated admin transport and workflow/repository modules. Routes remain
  SQL-free.
- Reuse existing response shapes, lifecycle state rules, audit actions, and
  batch error mapping through explicit platform-admin seams. Never fake an
  OWNER/ADMIN membership or weaken ordinary routes.
- Lock the namespace for every mutation. Ownership transfer also locks member
  rows and requires exactly one current OWNER; zero or multiple owners are an
  integrity error.
- New owner must already be a member. Direct OWNER add, role update, and owner
  removal remain forbidden.
- Mutation and audit row commit in the same transaction. Audit failure rolls
  back state. Actor, request ID, client IP, user agent, affected user/roles,
  and lifecycle reason are captured; email is not.
- Batch addition performs one durable transaction per item after a shared
  authorization preflight, so response counts describe committed rows.
- Candidate search uses SQL `NOT EXISTS`; do not reproduce upstream's
  first-500-member exclusion bug.
- No schema migration is required.

## OpenAPI And Frontend

Every route receives typed Pydantic request/response models. A deterministic
Python-focused exporter generates an admin namespace OpenAPI document and
TypeScript declarations; generated files are never hand-edited.

The frontend adds `/admin/namespaces` and a SUPER_ADMIN menu item, uses TanStack
Query and base-path-safe request helpers, keeps `/admin/namespace-analytics`
separate, and supports English, Simplified Chinese, and Traditional Chinese.
GLOBAL is read-only. Lifecycle and ownership actions require confirmation;
freeze/archive collect an audit reason.

## Verification Contract

- Exact route inventory, DTO/OpenAPI output, filters, stats, ordering, page
  bounds, and capability matrix.
- Unauthenticated 401, non-SUPER_ADMIN 403, bearer unsupported 403, invalid
  bearer 401, and session/mock SUPER_ADMIN success.
- Real PostgreSQL tests for counts, duplicate member races, sole-owner transfer,
  audit rollback, lifecycle races, and state/audit atomicity.
- Existing ordinary non-member routes remain forbidden.
- Frontend route/menu, cache invalidation, confirmations, error recovery,
  capability controls, three locales, typecheck, lint, full tests, and build.
- Final production browser smoke covers root and `/skillhub` with no console
  errors or horizontal overflow.

## Non-Goals

- No Java, Spring, Maven, schema migration, implicit SUPER_ADMIN membership,
  admin namespace create/edit/delete, or merging with Namespace Analytics.
- Do not copy arbitrary first-owner selection, N+1 membership lookup,
  first-500 candidate filtering, missing member/ownership audit, or ambiguous
  batch transaction semantics from upstream.
