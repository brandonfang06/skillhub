# 评分与收藏

## 收藏技能

点击技能详情页的"收藏"按钮可收藏技能。

查看已收藏的技能：
- Web：进入"我的收藏"
- CLI：`clawhub stars`

## 技能评分

可对技能进行 1-5 分评分：

1. 进入技能详情页
2. 点击评分区域
3. 选择评分（1-5 星）
4. 提交评分

可随时修改自己的评分。

## 文字评价

在已发布、可下载的技能详情页，可撰写最多 2000 个字符的文字评价。
可以修改或清除自己的评价，清除文字不会删除星级评分。被管理员隐藏的评价
不会出现在公开列表；作者编辑后仍保持隐藏，直到管理员恢复。
